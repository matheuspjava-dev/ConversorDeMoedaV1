Conversor de Moeda

Esse é um projeto simples feito em Java para praticar lógica de programação.

O programa converte valores entre Dólar e Real, usando uma taxa de câmbio fixa.

Como funciona
O programa pergunta qual moeda você possui (Dólar ou Real).
Dependendo da escolha, ele pede a quantidade que você tem.
Ele calcula e mostra o valor convertido para a outra moeda.

A taxa de conversão usada é: 1 Dólar = 5.60 Reais

Como rodar
Baixe ou clone o projeto.
Compile o código:
   javac Main.java
Execute:
   java Main
